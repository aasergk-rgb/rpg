# TITAN GRAFT（タイタン・グラフト）

部位奪取・3Dダークファンタジー・アクションRPG（Android 向け）

> 敵の最強の武器（部位）を斬り落とし、その場で自分の腕に繋いでぶっ放す。

Three.js（WebGL2）で描画する 3D アクションを TypeScript で実装し、Capacitor で Android ネイティブアプリとして包んでいます。
スタミナ制・ガチャ・課金武器はなく、完全オフラインで動作します（本編アンロックはデモ用のフラグのみで、決済処理は入っていません）。

## このビルドで遊べる範囲（縦切りスライス）

| 要素 | 内容 |
|---|---|
| 戦闘 | 3属性（打撃で装甲粉砕 → 斬撃で部位切断、刺突で弱点を突いて大ダウン）、ヒットストップ 0.03〜0.09 秒の手応えの差、金属音と肉断ち音・カメラ波形・ハプティクスの出し分け |
| ライブ・グラフト | 切断した部位に駆け寄って「接続」（0.5 秒の神経ケーブル演出）。接続中は攻撃が部位の技に変化。耐久エネルギーが尽きると崩壊 |
| オーバーロード・パージ | 接続した部位を暴走させ、爆弾として投げつけるフィニッシュ技 |
| 刃合わせ／見切り | 攻撃の瞬間に静止して避ボタンでパリィ。パリィできない赤い咆哮攻撃はステップを合わせるとスローになり、次の一撃が確定の強攻撃になる |
| 敵 | 瘴気の屍兵、狂える鎧騎士（大盾 → 盾グラフト）、岩殻の剛獣（剛腕 → 鉄格子をこじ開ける）、火喰い猟犬（顎 → 火炎放射・茨を焼く） |
| ボス | 処刑騎士ガラハッド。縦斬りをパリィすると右腕の装甲が剥がれ、斬り落とすと蒸気回転斧を奪える。右腕を失うと短剣の連撃モードに移る |
| 探索 | 炉心の廃教会（拠点）→ 血錆の回廊 → 城塞外郭（鉄格子・茨・二段ジャンプでしか届かない高台）→ 魔導エレベーター → 巨神の脊髄道 → 処刑場 → 本編の扉 |
| 育成 | 武器骨格5種（直剣・大剣・戦鎚・双刃・長槍）、機構パーツを合成すると溜め攻撃のモーションが変わる、ランダム特性、義体ソケット（左腕・脚部・背部） |
| 報酬分岐 | 頭部を壊して倒したか、部位を残して倒したかでレア素材が変わる（例：ボスの右腕を残して倒すと「蒸気回転機関」） |
| その他 | オートセーブ、拠点での休息とボス再戦、横画面固定、没入型フルスクリーン、Bluetooth／MFi コントローラー対応、動的解像度で 60fps（対応端末は 120fps）を維持 |

## 操作

| 操作 | タッチ | コントローラー | キーボード |
|---|---|---|---|
| 移動 | 画面左をドラッグ（フローティングスティック） | 左スティック | WASD |
| カメラ | 画面右をドラッグ | 右スティック | 矢印キー |
| 軽攻撃コンボ（最大4段） | 攻ボタンをタップ | X | J |
| 斬り上げ・対空ジャンプ斬り | 攻ボタンを上フリック | LB | I |
| 踏み込み突進斬り | 攻ボタンを横フリック | RB | L |
| 溜め強攻撃（部位切断フィニッシュ） | 攻ボタンを長押し | RT 長押し | K 長押し |
| ステップ回避 | 避ボタン（スティック入力中） | A | Space（移動中） |
| 刃合わせ（パリィ） | 避ボタン（静止中） | A（静止中） | Space（静止中） |
| オーバーロード・パージ | 避ボタンを長押しして離す（接続中） | LT | Space 長押し |
| 接続・調べる | 接続ボタン（近づくと表示） | B | E |
| ロックオン | ◎ボタン | R3 | Q |
| 部位ターゲット切替 | ロック中に画面右をスワイプ | 十字キー左右 | Z / C |
| 霊薬 | 霊薬ボタン | Y | R |

グラフト中はボタンの意味が部位の技に変わります（軽攻撃3段目 → 部位連携攻撃、上フリック → 対空技、横フリック → 装甲貫通突進、長押し → 部位固有の必殺技）。

## APK の入手とビルド

### GitHub Actions（推奨）
push するたびに `.github/workflows/android.yml` がデバッグ APK をビルドします。
Actions の実行結果ページから成果物 `titan-graft-debug-apk` をダウンロードし、端末にインストールしてください（提供元不明のアプリのインストールを許可する必要があります）。

### ローカルでビルド
Node.js 22、JDK 21、Android SDK（API 36）が必要です。

```bash
npm ci
npm run android:debug          # = build → cap sync → gradlew assembleDebug
# 出力: android/app/build/outputs/apk/debug/app-debug.apk
```

Android Studio で開く場合は `npx cap open android` を使います。

### ブラウザで遊ぶ・開発する

```bash
npm run dev        # http://localhost:5173 （キーボード／ゲームパッド／タッチ）
npm test           # 単体テスト（部位破壊・鍛冶・報酬分岐・ヒットストップ）
npm run build && npx vite preview --port 4173 &
npm run e2e        # Playwright による E2E スモークテスト（スクリーンショットを screenshots/ に保存）
```

URL に `?q=low|mid|high` を付けると画質プリセットを固定できます。

## ソース構成

```
src/
  main.ts              起動・タイトル／ポーズ／設定／拠点／アンロック画面
  core/                時間管理（ヒットストップ・スロー）、乱数、セーブ入出力
  render/              レンダラー（PBR・リムライト・動的解像度）、カメラ（シェイク波形・遮蔽物の半透明化）、
                       パーティクル、剣閃トレイル、手続き的アニメーション用リグ
  input/               タッチ（フリック派生UI）、ゲームパッド、キーボード → 共通アクション
  game/
    Game.ts            ゲーム全体（戦闘解決・インタラクト・グラフト・パージ・ドロップ）
    Player.ts          プレイヤーのステートマシン
    Parts.ts           部位ダメージ解決（3属性の破壊メカニクス）
    Enemy.ts           敵の基底クラス（AI・攻撃パターン・パリィ・ダウン）
    enemies/           屍兵・鎧騎士・剛獣・猟犬・処刑騎士ガラハッド
    Data.ts            武器骨格・グラフト技・素材・特性のデータ
    Build.ts           セーブデータ、キメラ鍛冶（モーション継承）、義体ソケット
    Drops.ts           部位破壊状態による報酬分岐
  world/               立体迷宮のデータとコリジョン
  ui/                  HUD、鍛冶場、メニュー
android/               Capacitor の Android プロジェクト（横画面・没入型・オフライン）
```

すべてのモデル・エフェクト・効果音は実行時にプロシージャル生成しているため、外部アセットはありません。
